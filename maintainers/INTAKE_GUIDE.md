# 维护者入库指南（从 Issue 到条目）

这份文档是给维护者/管理员看的。目标是：**把作者的 Issue 表单内容，整理成仓库中结构统一、可长期维护的条目**。

## 入库步骤

1. 选择分类：`mcp` / `skills` / `examples` / `tutorials`
2. 创建目录：`entries/<分类>/<资源短名>/`
3. 从模板拷贝：`entries/_template/` 下的 `meta.yml` 和 `README.md`
4. 把 Issue 里的内容填进去（尽量保留作者原话，但要结构化）
5. 更新 `INDEX.md`（把资源加到对应分类下）
6. 提交后回到 Issue：
   - 打标签：`已收录`
   - 贴上条目链接
   - 关闭 Issue

## 命名建议

- `<资源短名>` 尽量用英文/拼音/下划线，避免空格与特殊符号  
  示例：`terrain_exporter`、`pathfinding_mcp`

## 安全与风险提示（建议）

如果作者资源涉及：
- 联网调用（模型、API、下载依赖）
- 执行脚本/命令
- 读写本地文件

请在条目 `README.md` 里明确写到「会做什么」「需要用户确认什么」。
