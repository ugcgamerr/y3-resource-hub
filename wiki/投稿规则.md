# 投稿规则

## 方式 A：一键填表（推荐，不会 Git 也能用）

👉 [Gitee Issue 投稿入口](https://gitee.com/kky3rpg/y3-resource-hub/issues/new?template=resource_submit.yml)

你只需要填这 6 项（其余可以空着）：

1. 资源分类（必选）
2. 资源名称（必填）
3. 一句话用途（必填）
4. 安装/使用步骤（必填，能复现即可）
5. 资源链接或附件（必填：仓库 / 网盘 / 截图）
6. 适配版本（选填）
7. 风险说明（选填：是否联网、是否执行命令等）
8. 作者署名（选填）
9. 联系方式（选填）

> 维护者会审核 → 在仓库打 topic → 把这条资源收录到 [资源索引](资源索引)。

---

## 方式 B：会 Git 的作者

1. Fork 仓库
2. 在 `entries/<分类>/<你的资源名>/` 下新建文件夹
3. 写 `README.md` + `meta.yml`
4. 在 [INDEX](https://gitee.com/kky3rpg/y3-resource-hub/blob/main/INDEX.md) 对应分类下加一行
5. 提一个 Pull Request

---

## 维护者动作

- 审核 → 在仓库打 topic：`kky-skill` / `kky-mcp` / `kky-doc`
- 录入 → 把这条资源加进 [资源索引](资源索引)
- 通知 → 在对应 Issue 里回复作者

---

## ❗ 红线

- 不收账号、Token、密钥
- 不收未授权转载内容
- 不收明显有安全风险的执行脚本
